# Font provenance

Source Serif 4, obtained from the `google/fonts` GitHub repository, directory `ofl/sourceserif4`, via the GitHub Contents and Git Blob APIs on 21 October 2026.

Upstream variable files: `SourceSerif4[opsz,wght].ttf` and `SourceSerif4-Italic[opsz,wght].ttf`.
Licence: SIL Open Font License, supplied as `OFL.txt`.

The Regular, Bold and Italic static proof assets were instantiated with fontTools at optical size 11 and weights 400/700/400 respectively. Static font naming records were assigned distinct face/PostScript names to avoid PDF font-subset collisions. No glyph outlines were manually edited. The variable originals and licence are retained.

PDFs embed font subsets. DOCX files specify the font by name but do not embed it; install these font assets or use a properly licensed compatible replacement before editing/reflowing in Word.
