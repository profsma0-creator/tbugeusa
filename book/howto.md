# HOW TO USE|How to Use This Book

The book is designed for a doctoral course that combines seminars, supervised practice and independent reading. It can be read sequentially, but it is also organised so that it can be used flexibly.

## Sequential reading

Chapters 1 to 4 establish the reasoning and measurement framework on which everything else depends. Readers who are new to assessment should read these chapters first, in order. Chapters 5 to 16 can then be read according to the curriculum, although each assumes familiarity with the concepts introduced in Part I.

## Reading alongside a placement

Each chapter's Advanced Case Conference is a worked example of the reasoning the chapter describes. Readers on placement are encouraged to read the case conference alongside their own caseload, and to write their own case conference in the same format for supervision. The format — referral, evidence, reasoning, decision, teaching point — is deliberately the same as the structure of a well-written report.

## Diagnostic systems

Two classification systems are referred to throughout: DSM-5-TR and ICD-11. They are not interchangeable, and the differences matter for some presentations, notably personality disorder, post-traumatic stress disorder and substance use. Readers should consult the primary texts for criteria, and should note which system a given service uses, since the criteria applied affect eligibility for treatment and for funding.

## Instruments

The book discusses instrument families and the principles by which they are evaluated, but it does not reproduce items, scoring rules or norm tables. When learning a specific instrument, readers should work from the manual, under supervision, with attention to the reliability, validity, norm group and stated limits of interpretation discussed in Chapter 3.

## The learning features

Each chapter contains:

- **Learning objectives**, which state what the reader should be able to do after the chapter.
- **Key terms**, listed at the start and defined in the glossary.
- **Numbered sections**, which move from principle to application.
- **Tables**, which summarise distinctions that are easily confused.
- **Figures**, which present the chapter's conceptual structure.
- **An Advanced Case Conference**, which demonstrates the reasoning on a composite case.
- **A chapter summary**, which restates the argument.
- **Review questions**, which test comprehension and application.
- **Discussion questions**, which are designed for seminar use and have no single correct answer.
- **Further reading**, which identifies the sources on which the chapter draws.

## A note for instructors

The discussion questions are written to expose disagreement rather than to elicit a correct answer, and they work best when students are asked to defend a position and then to argue the opposite. The case conferences can be used as the basis for role-play, for written formulations, or for peer review exercises in which students critique each other's reasoning. Appendix A provides a planning and quality checklist that students can use as a self-assessment tool before submitting assessed work.
